# FORGE NYC Modular GTA RP Bundle

This repository contains the updated FORGE bundle configuration assets for a modular, stream-safe GTA RP ecosystem inspired by New York City + Long Island.

## Included

- `schema/world-config.schema.json`: Updated world configuration schema.
- `config/region-presets.json`: Region and environment presets for NYC/LI + prison/airport/plane modules.
- `config/stream-groups.json`: Stream group definitions for modular loading.
- `config/transition-nodes.example.json`: Transition node examples connecting modules.
- `examples/fallback-prompts.json`: Fallback generator prompt support targets.
- `docs/export-naming.md`: Export naming patterns for FiveM, Unreal, video, and pack outputs.
- `docs/modular-layout.md`: Recommended main exterior and interior module layout strategy.
- `prompts/app-builder-prompt.txt`: Exact integration prompt for the app builder.
